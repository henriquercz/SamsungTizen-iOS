## References and visual inspiration

The public [samsung-tv-ws-api](https://github.com/xchwarze/samsung-tv-ws-api) project informed the Smart View protocol behavior. Samsung app IDs in `app-catalog.json` come from the community list maintained by [homebridge-samsung-tizen](https://tavicu.github.io/homebridge-samsung-tizen/extra/applications.html). The native Swift implementation is part of this project; neither project is bundled as a dependency.

The menu bar layout was inspired by [vorssaint-utils](https://github.com/vorssaint/vorssaint-utils). The interface in this project is implemented in SwiftUI and AppKit.
